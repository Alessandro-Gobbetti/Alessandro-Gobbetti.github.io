# Alessandro Gobbetti: Personal Website

This repository contains the source code for my personal website, available online at [alessandro-gobbetti.github.io](https://alessandro-gobbetti.github.io).

## About

It serves as a central hub for my academic background, professional experience, and personal projects.

## Tech Stack

The site is built from scratch with a focus on performance, responsive design, and minimal dependencies:
* **HTML5 / CSS3** (Vanilla, with light/dark mode support)
* **JavaScript** (Vanilla)
* Hosted directly via **GitHub Pages**
